# Changes on 12 November 2026: the kiosk UI connected to the backend

Two commits on `main`, from `3a3c773` (the previous state) to `ad51339`:

| Commit | What |
|---|---|
| `4c985bc` | Backend and camera sidecar: serve the kiosk UI, a sharp camera preview shaped to the screen, the 3-2-1 hold time, the camera rotation check. |
| `ad51339` | The team's kiosk UI, connected to the backend, added as `Kyra-UI-V1/`, with setup and guide updates. |

See everything with `git diff 3a3c773 ad51339`, or one file with `git diff 3a3c773 ad51339 -- <path>`.

**In short**

- One clone runs the whole mirror. `./setup.sh` builds the UI, `npm start` serves it at
  `http://localhost:3000/Kyra-UI-V1/`, and `npm run links` prints the link with the access token.
- The backend owns the camera. The UI shows its preview; hand tracking, wave and pinch work on it.
- New in the UI: a consent screen, which starts the visit, and a results screen. Results show the
  undertone, the palette, the look, and Love it, Show another, Take it home (a QR code) and I'm done.
- `npm run camera-check -- --apply` works out the `CAMERA_ROTATION` a camera mounted on its side needs.
- Tests: backend 113, sidecar 166, UI 13, all passing (also on GitHub CI).
